# ScoutVision Validation Framework v1.0

This document defines the validation rules for every competency, profile and intelligence module.

---

# General Principles

1. Every conclusion must be traceable to measurable KPIs.

2. No profile may use unavailable data.

3. Every profile must be explainable.

4. Every competency must have a clear football meaning.

5. Every intelligence engine must be deterministic.

---

# Competency Validation

A competency is valid only if:

- it is built from measurable KPIs;
- every KPI has a football rationale;
- the competency measures only one football dimension;
- duplicated KPIs are avoided whenever possible.

---

# DNA Profile Validation

A DNA profile is valid only if:

- it uses at least three competencies;
- it represents a real football role;
- it is distinguishable from every other profile;
- every competency contributes with a defined weight.

---

# Development Validation

A development area is valid only if:

- it is supported by measurable competencies;
- it identifies an improvable football quality;
- it does not duplicate another development profile.

---

# Position Model Validation

Every position model must:

- use only relevant competencies;
- ignore irrelevant competencies;
- reflect the tactical role of the position.

---

# Report Validation

Every report must answer:

1. What profile was assigned?

2. Why?

3. Which competencies support it?

4. Which KPIs generated those competencies?

If these four questions cannot be answered, the report is considered incomplete.
