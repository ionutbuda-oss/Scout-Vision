# ScoutVision Position Models v1.0

This document defines the competency model used for every playing position.

The objective is to evaluate players according to the football demands of their role.

Competencies are weighted only after they have been validated within the Competency Framework.

---

# Centre Back (CB)

Core competencies:

- Defending
- Distribution
- Progression
- Ball Winning

Secondary competencies:

None

Excluded competencies:

- Goal Threat
- Chance Creation

Football objective:

Protect the defensive line while initiating possession.

---

# Full Back / Wing Back (FB/WB)

Core competencies:

- Defending
- Ball Carrying
- Progression
- Chance Creation

Secondary competencies:

- Offensive Duels

Excluded competencies:

- Goal Threat

Football objective:

Provide defensive stability while supporting wide progression.

---

# Defensive Midfielder (DM)

Core competencies:

- Defending
- Distribution
- Progression
- Ball Security

Secondary competencies:

- Ball Winning

Excluded competencies:

- Goal Threat

Football objective:

Protect central space while controlling possession.

---

# Central Midfielder (CM)

Core competencies:

- Progression
- Distribution
- Ball Carrying
- Creativity

Secondary competencies:

- Ball Security

Football objective:

Connect defensive and attacking phases.

---

# Attacking Midfielder (AM)

Core competencies:

- Creativity
- Progression
- Ball Carrying
- Goal Threat

Secondary competencies:

- Distribution

Football objective:

Create and accelerate attacking play.

---

# Winger

Core competencies:

- Ball Carrying
- Chance Creation
- Offensive Duels
- Goal Threat

Secondary competencies:

- Progression

Football objective:

Create numerical superiority and attacking opportunities from wide areas.

---

# Striker (ST)

Core competencies:

- Goal Threat
- Finishing
- Link Play
- Offensive Duels

Secondary competencies:

- Ball Carrying

Football objective:

Convert chances while connecting attacking play.
